# ShiroMamo ゲーム仕様書

更新日 2026-11-12 / 現在制作中のPC版

## どんなゲームか

最大2人で協力し、敵から中央の砦を守る一人称の3Dゲーム。剣で近くの敵を斬り、本から魔法の球を撃ち、倒した敵から経験値や武器を集める。左右に持つ武器を自分で選び、成長しながら3回の戦闘を乗り切る。

現在は戦闘と装備の基礎を制作している。以下は現在の実装に基づく内容で、数値は調整中。最新機能の実操作・見た目・2人プレイの確認が残っている。詳しい確認状況は[引き継ぎ](HANDOFF.md)を参照する。

## 人数と始め方

PCのマウスとキーボードで操作する。ホストが部屋を作り、表示された参加コードをもう1人へ伝える。参加者が合流したら、ホストがStart Gameを押す。1人でも開始できる。

## 1試合の流れと勝敗

戦闘2分と回収1分を、3ウェーブ繰り返す。最後の回収が終わるまで砦を守れば勝利。砦のHPは1,000で、0になると敗北する。予定どおり進む1試合は約9分。

戦闘が終わると、残っている敵は報酬を落とさずに消える。落ちている経験値と武器は戦闘中にも回収中にも拾える。次の戦闘が始まると拾い残しは消える。勝敗後はホストがRで再戦する処理があるが、最新機能を含む再戦は未確認。

## 操作

| 操作 | 動作 |
| --- | --- |
| WASD・矢印キー | 移動 |
| マウス | 視点を動かす |
| Space | 接地中にジャンプ |
| 移動キー＋Shift | 入力方向へ短時間の高速移動 |
| 左クリック | 左手の武器を使う |
| 右クリック | 右手の武器を使う。武器がなければ素手攻撃 |
| I | 持ち物を開く・閉じる |
| Esc・Close | 持ち物を閉じる |
| R | 勝敗後にホストが再戦 |

左手が空の場合、左クリックでは攻撃しない。攻撃はクリックごとに行い、押しっぱなしで連射する操作は現在ない。

ジャンプの調整値は高さ1.5m。高速移動は4mを約0.15秒で進み、再使用まで1.5秒。移動キーがなければ発動しない。壁や砦の手前で止まり、空中でも使える。数値は今後調整する。

## 戦闘

| 武器 | 現在できること |
| --- | --- |
| Crystal Sword | 片手剣を振り、刃の形と通った軌跡で敵への命中を調べる。一振りで最大1体に1回ダメージ |
| Magic Book | 視点の方向へ仮の球を発射。球は最初に当たった敵へ1回ダメージを与え、敵・壁・地面への命中や寿命で消える |

剣と本の組み合わせ、剣2本、本2冊を左右に装備できる。同じ1本を両手へ同時に装備することはできない。左右の攻撃間隔は独立している。現在の攻撃間隔は基本0.5秒で、剣の振りがそれより長い場合は振り時間に従う。

攻撃を受けて生き残った敵は押し戻され、その間は移動と攻撃を一時停止する。球は自分や相棒には当たらない。

## 武器を拾って選ぶ

敵は経験値オーブと、確率で剣か本を落とす。落ちた物は近くの生きているプレイヤーへ吸い寄せられ、拾った人のものになる。

武器は自動装備されず、持ち物へ入る。Iで一覧を開き、左右の手へ装備する。解除した武器も持ち物に残る。反対の手で装備中の1本を選ぶと左右が入れ替わる。

武器1本ごとにレア度と性能を抽選し、拾得や装備変更をしても値を維持する。同じ種類・同じレア度でも性能に差がある。現在は攻撃力・防御力・最大HPの3項目を抽選する。レア度の仮設定はCommon 70%、Rare 25%、Epic 5%。

攻撃力はその武器による攻撃に使い、防御力と最大HPは左右の武器の分を合算する。剣・本の基本攻撃補正は+5で、抽選結果に応じた補正が加わる。

**持ち物一覧のレア度・性能表示は、個体ごとの値への対応待ち。** 内部の性能と一覧表示が一致しない場合がある。持ち物画面を開いている本人は操作を止めるが、敵と戦闘時間は進み続ける。

## 成長と復活

| 能力 | レベル1 | 1レベルごとの増加 |
| --- | --- | --- |
| 最大HP | 100 | 15 |
| 基礎攻撃力 | 12 | 2 |
| 基礎防御力 | 0 | 0.5 |
| 移動速度 | 6 | 0.1 |

経験値は拾った人に入り、レベルアップするとHPが全回復する。HPが0になると3秒後に初期位置で全回復して復活する。プレイヤーの死亡後も、砦の防衛は続く。

## 敵

| 敵 | 初登場 | 現在の特徴 |
| --- | --- | --- |
| Goblin | 第1ウェーブ | HP30、速度3。近くのプレイヤーを狙う |
| Orc | 第2ウェーブ | HP50、速度2。プレイヤーを狙う距離が短い |
| Witch | 第2ウェーブ | HP30、速度1。離れた位置から攻撃する。敵側の弾表示は現在ない |

数値は第1ウェーブ相当の基準値。敵は近くに生存プレイヤーがいれば優先し、いなければ砦へ向かう。後半ほどHP・攻撃力・速度が上がり、出現間隔も短くなる。最大同時出現数は40で、人数別の難易度補正は現在ない。

## 画面と今後の方向

画面にはウェーブ、残り時間、砦HP、自分のHP・レベル・経験値・装備、通知、勝敗を表示する。相棒の状態を表示する処理はあるが、現在のシーンでは表示欄が未設定。

今後は同じ種類でも性能の違いから武器を選ぶ遊びを広げたい。会心、回復、状態異常、複数体攻撃など34項目が候補に選ばれているが、現在の個体差として実装された効果は攻撃・防御・最大HPまで。盾・両手武器・残りの能力は詳細と優先順位を決めてから進める。防具を新たに制作するかは保留。

将来はPCにつないだVRゴーグルでも遊べることを目指す。武器の位置と向きを共通の戦闘処理へ渡す土台がある。VR機器への対応、追跡入力、VR操作はこれから設計・実装する。
