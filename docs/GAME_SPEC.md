# ShiroMamo ゲーム仕様書

更新日 2026-11-19 / 現在制作中のPC版

## どんなゲームか

最大2人で協力し、敵から中央の砦を守る一人称の3Dゲーム。剣で近くの敵を斬り、本から魔法の球を撃ち、倒した敵から経験値や武器を集める。左右に持つ武器を自分で選び、成長しながら3回の戦闘を乗り切る。

現在は戦闘と装備の基礎を制作している。以下は現在の実装に基づく内容で、数値は調整中。最新機能の実操作・見た目・2人プレイの確認が残っている。詳しい確認状況は[引き継ぎ](HANDOFF.md)を参照する。

## 人数と始め方

PCのマウスとキーボードで操作する。ホストが部屋を作り、表示された参加コードをもう1人へ伝える。参加者が合流したら、ホストがStart Gameを押す。1人でも開始できる。

画面とUIの制作基準はFull HD（1920×1080・16:9）に決定した。ウィンドウ／フルスクリーンなどの画面モードは未決定。現在の起動サイズ設定は1024×768で、制作基準への設定変更と実表示の確認はこれから行う。

## 1試合の流れと勝敗

戦闘2分と回収1分を、3ウェーブ繰り返す。最後の回収が終わるまで砦を守れば勝利。砦のHPは1,000で、0になると敗北する。予定どおり進む1試合は約9分。

戦闘が終わると、残っている敵は報酬を落とさずに消える。落ちている経験値と武器は戦闘中にも回収中にも拾える。次の戦闘が始まると敵が落とした拾い残しは消えるが、プレイヤーが落とした武器は残る。勝敗後はホストがRで再戦する処理があるが、最新機能を含む再戦は未確認。

## 操作

| 操作 | 動作 |
| --- | --- |
| WASD・矢印キー | 移動 |
| マウス | 視点を動かす |
| Space | 接地中にジャンプ |
| 移動キー＋Shift | 入力方向へ短時間の高速移動 |
| 左クリック | 左手の武器を使う |
| 右クリック | 右手の武器を使う。武器がなければ素手攻撃 |
| I | 持ち物を開く・閉じる |
| Esc・Close | 持ち物を閉じる |
| R | 勝敗後にホストが再戦 |

左手が空の場合、左クリックでは攻撃しない。攻撃はクリックごとに行い、押しっぱなしで連射する操作は現在ない。

ジャンプの調整値は高さ1.5m。高速移動は4mを約0.15秒で進み、再使用まで1.5秒。移動キーがなければ発動しない。壁や砦の手前で止まり、空中でも使える。数値は今後調整する。

## 戦闘

| 武器 | 現在できること |
| --- | --- |
| Crystal Sword | 片手剣を振り、刃の形と通った軌跡で敵への命中を調べる。一振りで触れた複数の敵へ各100%ダメージ。同じ敵には一振り1回 |
| Magic Book | 視点の方向へ仮の球を発射。球は最初に当たった敵へ1回ダメージを与え、敵・壁・地面への命中や寿命で消える |
| 盾 | 前へ突き出して複数の敵へ小ダメージとノックバック。同じ敵には一振り1回。装備中は受けるダメージを常時軽減 |

剣と本の組み合わせ、剣2本、本2冊を左右に装備できる。同じ1本を両手へ同時に装備することはできない。左右の攻撃間隔は独立している。現在の攻撃間隔は基本0.5秒で、剣の振りがそれより長い場合は振り時間に従う。

攻撃を受けて生き残った敵は押し戻され、その間は移動と攻撃を一時停止する。球は自分や相棒には当たらない。

敵頭上付近へ自分のダメージ数字を表示する。通常は白、会心は大きめの黄色で、少し浮き上がって消え、撃破後も数字は残る。壁越しには見せない。ホスト素手の命中から表示状態までと、撃破・会心・レベルアップ停止への追従は隔離検証済み。実画面の見やすさ、剣・魔法との表示統合、参加者端末での表示は確認待ち。

## 複数命中の確認状況と、今後のスキル方針

剣と盾バッシュの複数命中は実装・隔離検証済み。各敵へ100%ダメージ、同じ敵は一振り1回、壁で遮断する。実クリックでの手応えと見た目は確認待ち。素手と魔法は従来のまま。

その後の武器スキルは、剣に毒、本に貫通、通常盾に反射を固有で1個付ける。共通スキルは武器生成時にコモン0個・レア1個・エピック2個を抽選。同じスキルも重複でき、性能値は固定、効果は基本加算する。拾い直しでスキルは変わらない。進化は今回作らない。

貫通は1個で最大3体へ減衰なし。盾の反射は被弾時に自動で働き、軽減前ダメージの20%が1個の初期値。毒の強さ・持続時間、複数盾の反射、貫通重複の上限などは未決定。スキル実装は別途仕様を決めてから着手する。

## 武器を拾って選ぶ

敵は経験値オーブと、確率で剣・本・盾のいずれかを落とす。落ちた物は近くの生きているプレイヤーへ吸い寄せられ、拾った人のものになる。

武器は持ち物へ入り、空いている手があればその場で自動装備する。両手が空なら右手、右手だけ装備中なら左手に持つ。両手とも装備中なら保管だけを行う。Iで一覧を開き、左右の手へ装備する。解除した武器も持ち物に残る。反対の手で装備中の1本を選ぶと左右が入れ替わる。

持ち物行の「落とす」で、武器を足元へ置いて味方へ渡せる。装備中の武器も落とせ、その手は空になる。レア度と性能は同じまま。味方はすぐ拾え、落とした本人は回収範囲の外へ一度離れてから再取得できる。自分で落とした武器はウェーブが変わっても残るが、再戦時のシーン再起動では消える。実際のボタン操作と、歩いて受け渡す動作の確認は残っている。

武器1本ごとにレア度・攻撃倍率・HP補正を抽選し、拾得や装備変更をしても値を維持する。同じ種類・同じレア度でも倍率に差がある。レア度の仮設定はCommon 70%、Rare 25%、Epic 5%。敵が装備を落とすときは剣・本・盾から同じ重みで選ぶ。

攻撃ダメージは本人の攻撃力×使う手の武器倍率で決まり、会心時はさらに会心倍率が掛かる。武器の加算攻撃力と本人の防御力は廃止した。HP補正は装備中の左右分を合算する。盾の軽減率はコモン10%・レア20%・エピック30%の仮値で、両手に20%盾なら最終36%軽減となる。所持品にあるだけの盾は軽減しない。

持ち物一覧は個体ごとのレア度・攻撃倍率・盾軽減率・HP補正を表示する。戦闘の左右欄は剣・本・素手なら計算済みの「攻撃力」、盾ならその盾1枚の軽減率を「防御力%」として表示する。本人攻撃力・合成軽減率の行は省略する。新文言の実画面確認はこれから行う。持ち物を開いている本人は操作を止めるが、敵と戦闘時間は進み続ける。

持ち物は攻撃倍率・軽減率・HPを横に比較できる表へ変更した。エピック→レア→コモン順に自動で並び、同じレア度では拾った順になる。装備中は白枠と左手・右手の表示、選択中は背景色で分かる。武器を選んで下の固定ボタンから装備・落とすを行う。合成武器14個で選択・左手装備・落とす・スクロールは確認されたが、実戦での拾得と2人通信は確認待ち。

列名は「攻撃倍率・軽減率・HP」で、見出しをクリックすると高い順に並べ替える。同じ値ならレア度の高い順、その後は拾った順。レア度見出しで通常のレア度順へ戻せる。倍率と軽減への切替後の実クリックは確認待ち。

## 成長と復活

| 能力 | レベル1 | 1レベルごとの増加 |
| --- | --- | --- |
| 最大HP | 100 | 15 |
| 基礎攻撃力 | 12 | 2 |
| 移動速度 | 6 | 0.1 |

経験値とレベルは2人共有。どちらが経験値を拾ってもチームへ加算し、レベルアップ時は生存者のHPが全回復する。従来の自動成長に加え、各自がランダムな3択から自分の強化を選ぶ。全員が選び終わるまでゲームと残り時間は停止する。先に選んだ人は相棒を待つ。

誤選択を防ぐため、選択画面が出たらクリック・決定キーを離して約0.35秒待ち、その後に改めて選ぶ。連打中は受付を開始しない。複数レベルでは毎回待ち直す。実際の連打操作での改善確認はこれから行う。

強化候補は攻撃・最大HP・会心率・会心ダメージ・攻撃速度・移動速度・ジャンプ力の7種類で、1回の3択には同じ能力が重ならない。防御候補は削除した。複数レベル上がれば順に選ぶ。強化量は調整中。選んだ能力と武器の所持品は個人別に保持する。

HPが0になると3秒後に初期位置で全回復して復活する。選択中は復活待ちも停止するが、死亡中も強化を選べる。途中参加者は共有レベルへ合流して過去の分を選び、切断した人の選択は待たない。再戦では共有成長と個人強化がリセットされる。新しい選択画面の実クリックと別PC通信は確認待ち。

## 画面と今後の方向

検証用の制作者モードを追加した。Unity EditorまたはDevelopment Buildのホスト本人がF2で開き、チームの共有レベル変更、武器とレア度を選んだ持ち物への追加、敵の停止・再開を行う。レベルを上げた分の強化選択も発生する。画面を閉じても敵停止は続き、プレイヤーは攻撃できる。制作者モードの敵停止だけではウェーブ時間は止まらない。F2と画面の実操作、実際のビルドでの利用は確認待ち。

日本語の仮UIを実装した。上中央にウェーブと砦HP、右上に時間、左上に相棒、左下に自分の状態、下部に左右武器、中央に照準を置き、通知と勝敗も表示する。自分と砦のHPにはバーを付ける。相棒欄は実行時に生成する。Full HDを基準に配置するが、日本語フォントの読込・文字や配置・実操作は実画面で未確認。

武器の文字色はコモンが白、レアが青、エピックが紫。左右の武器、持ち物、拾得・自動装備通知へ反映する。消えていた時間欄への対処もコードに入っているが、時間と文字色の実画面での修正確認はこれから行う。

今後は個体差で武器を選ぶ遊びを広げたい。過去に34項目が候補に選ばれたが、その後防御は廃止し、現在の個体は攻撃倍率・HP補正・盾のレア度別軽減を使う。両手占有武器・残りの能力・武器スキルは詳細と優先順位を決めてから進める。盾の実モデルと動作、実戦での見やすさは受入確認待ち。防具を新たに制作するかは保留。

将来はPCにつないだVRゴーグルでも遊べることを目指す。武器の位置と向きを共通の戦闘処理へ渡す土台がある。VR機器への対応、追跡入力、VR操作はこれから設計・実装する。
